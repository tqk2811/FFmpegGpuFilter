# TqkLibrary.FFmpegTransition

GPU ports of the transitions of [tqk2811/TqkLibrary.FFmpegTransition](https://github.com/tqk2811/TqkLibrary.FFmpegTransition). Each package is a `progress` (0 to 1) driven transition between two clips.

| Package | Original class |
| --- | --- |
| [clock-wipe](clock-wipe/README.md) | `ClockTransition` |
| [collapse](collapse/README.md) | `CollapseTransition` |
| [expand](expand/README.md) | `ExpandTransition` |
| [dip-to-color](dip-to-color/README.md) | `FadeInTwoTransition` |
| [crossfade](crossfade/README.md) | `CrossFadeTransition` |
